Connection Instructions

Quick guides to map CloudDrive on your favorite operating system

Windows File Explorer

1. Open File Explorer, right-click This PC, then select Add a network location.
2. Click Next, then select "Choose a custom network location".
3. Paste the WebDAV Server URL above and enter your Username & Password.

macOS Finder

1. Open Finder, press Cmd + K (or click Go, then Connect to Server).
2. Paste the WebDAV URL and click Connect with your credentials.

iPhone / iPad (Files App)

1. Open the Files app, tap the ... (More) icon at the top right, then select Connect to Server.
2. Enter the WebDAV URL, choose Registered User, and sign in.
